# Visual references

References belong to individual scene configurations and must have the same pixel dimensions as a captured VM output.

Place locally approved *real* screenshots here (for instance launcher.png). Image-generated mockups are concept guidance only: do not use their photorealistic textures, fictional filenames or simulated output as hard pixel-golden tests.

This directory intentionally contains no approved reference PNG yet. A scene's first captured screenshot is a baseline candidate, **not** automatic acceptance. Generated differences, reviews and run logs belong under ../artifacts/ and are gitignored.
