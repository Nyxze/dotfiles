# Personal skills

Each directory below contains a reusable task workflow linked into Codex,
Claude Code, and OpenCode. Open a skill only for its trigger. Provider-owned
skills remain in their provider directories.

| Skill | Open when |
| --- | --- |
| [commit](commit/SKILL.md) | Creating a selective conventional commit. |
| [create-cli](create-cli/SKILL.md) | Designing or revising a command-line interface. |
| [frontend-design](frontend-design/SKILL.md) | Building a web component, page, or application. |
| [markdown-converter](markdown-converter/SKILL.md) | Converting a file or document to Markdown for analysis. |
| [repository-architecture](repository-architecture/SKILL.md) | Documenting an unfamiliar repository as an architecture guide. |
| [skill-creator](skill-creator/SKILL.md) | Creating, editing, or evaluating a reusable skill. |
