# Agent resources

| Resource | Open when |
| --- | --- |
| [Personal skills](../../skills/INDEX.md) | Selecting or maintaining a reusable task workflow shared by all providers. |
| [Installation index](../../MAIN.md) | Installing or repairing global instructions, skill links, or provider agents. |
| [Agent definitions](../../agents/) | Adding a reusable provider agent; this directory currently has no definitions. |

Provider-owned skills remain in provider directories and are not imported into
the personal shared skills directory without a deliberate ownership decision.
Capture a provider-written personal skill into `../../skills/` during the same
task, then link it to all providers.
